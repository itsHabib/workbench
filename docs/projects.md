# Agentic projects

Current public projects only; private and archived repositories are omitted.
Updated July 31, 2026.

## Workbench and infrastructure

- [workbench](https://github.com/itsHabib/workbench) — Go control plane for governed agentic development: merge gates, risk triage, trace diagnostics, escalation notifications, and related tools.
- [ship](https://github.com/itsHabib/ship) — Durable workflow engine for launching coding agents, inspecting runs, and driving parallel work streams toward reviewed PRs.
- [dossier](https://github.com/itsHabib/dossier) — Markdown-backed project memory and MCP server for plans, tasks, decisions, and shipped artifacts.
- [rooms](https://github.com/itsHabib/rooms) — Disposable Firecracker microVMs for isolated agent runs with explicit inputs, outputs, and teardown.
- [orchestra](https://github.com/itsHabib/orchestra) — DAG runner that executes dependent AI agents tier by tier and forwards upstream results downstream.
- [huddle](https://github.com/itsHabib/huddle) — Slack-backed, operator-visible coordination rooms with attributed identities for multiple agents.
- [tower](https://github.com/itsHabib/tower) — TUI, CLI, and MCP view of parallel worktrees, pull requests, CI, and review state.
- [hooks](https://github.com/itsHabib/hooks) — Deterministic Claude Code hooks that ferry workflow metadata between GitHub and the agentic workbench.
- [skills](https://github.com/itsHabib/skills) — Opinionated, reusable development workflows for AI coding assistants.
- [skill-sync](https://github.com/itsHabib/skill-sync) — CLI for projecting one canonical Agent Skills catalog across Claude Code, Codex, Copilot, Gemini, and other harnesses.
- [sense](https://github.com/itsHabib/sense) — Go SDK for semantic assertions and structured extraction from nondeterministic model output.
- [cortex](https://github.com/itsHabib/cortex) — Elixir/OTP multi-agent reference system with DAG, mesh, gossip, container, Kubernetes, and LiveView surfaces.

## Sandboxes and examples

- [agent-sandbox](https://github.com/itsHabib/agent-sandbox) — Live integration sandbox where agents can safely push branches and open real test PRs.
- [cc-sbx](https://github.com/itsHabib/cc-sbx) — Learner-project sandbox comparing Claude Code teams, subagents, and default single-agent workflows.
- [roll-call-voice-demo](https://github.com/itsHabib/roll-call-voice-demo) — Go proof of concept for source-grounded, interruptible Realtime AI voice standups.
- [agent-hackathon-cli](https://github.com/itsHabib/agent-hackathon-cli) — Educational hackathon run by agent developers and agent judges using Claude Code teams.
- [babel-protocol](https://github.com/itsHabib/babel-protocol) — Experiment in agents inventing and compressing their own inter-agent communication language.
- [course-builder-cache](https://github.com/itsHabib/course-builder-cache) — Project-based cache-proxy course produced through a multi-agent planning and implementation workflow.
- [pubsub-router](https://github.com/itsHabib/pubsub-router) — Kafka-backed routing system built with Claude Code teams as a multi-agent learning project.
- [wellness-team](https://github.com/itsHabib/wellness-team) — CrossFit training program assembled by eight specialized AI coaching agents.
- [ADT verbal-password investigation](https://github.com/itsHabib/cc-sbx/blob/main/ADT-PLUS-VERBAL-PASSWORD-FIX.md) — Agent-led reverse engineering of a production registration deadlock using browser automation, bundle analysis, and WebSocket tracing.
